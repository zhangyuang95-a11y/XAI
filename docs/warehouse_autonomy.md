# 物流仓库自主决策审计 · 2026-09-08

当前 v68 的执行包含神经提议、规则动作掩码、人工 logit 评分和输出后的动作选择。此次为本地同权重消融：不训练、不选择 checkpoint、不改线上入口、不写入原实验数据库。

## 可试玩入口

运行 `python3 -B -m ui.warehouse_autonomy_server --port 8000`，打开 http://127.0.0.1:8000/。方向键/WASD 移动，空格等待；每次输入一个联合步。支持中英文、历史回放、独立保存重开和进程重启恢复。所有模式使用同一 v68 NPZ，默认选择“自主神经头消融”和固定最大概率；可以切换固定种子采样。新局记录模式，不能在同一局中途改变执行方式。

页面的“动作接管”只统计 Actor 提议与提交给环境的 AI 动作不同的次数；碰撞解析导致的停留另记 `ai_blocked`，不当作策略接管。回放不推进状态。解释接口未接入，因为原解释与消融策略不匹配。

## 四层控制边界

| 模式 | 输出后选择 | 动作掩码 | 前向评分与输入 |
|---|---|---|---|
| guarded | 原有协调选择器 | 原规则掩码 | 原 forward、目标和计划特征 |
| actor_direct | 无 | 原规则掩码 | 原 forward、目标和计划特征 |
| unmasked_actor | 无 | 仅墙体/边界/状态等静态合法性 | 原 forward、目标和计划特征 |
| learned_only | 无 | 仅静态合法性 | 四个神经分量，移除人工评分和规则目标/计划输入 |

严格消融保留 base、structured、participant 神经残差、deadlock 神经残差；排除 29 项人工 bonus/penalty，包括名称虽是可训练 scalar、形式却仍由手写状态规则决定的项。保留原神经头 tanh 幅度，参与者角色类型仍用于残差路由；移除死锁残差的人工触发门控。原权重完全不变，但执行函数与输入分布发生改变，尤其死锁残差会在原激活范围之外运行。这不是“完全相同的原策略”，更不是已经验收的新纯 RL 模型。

自主观察维度仍为 470（全局 948），直接编码位置、电量、持物、任务、地图和已发生动作；不把程序生成的目标/计划送入 Actor。原环境仍保留这些字段供历史计分、训练奖励和审计使用；既有参与者绕路分也保留。相同输入动作下物理状态、电量、取送、原用户得分与 RNG 一致。

## 诊断协议与结果

每种模式 × 三种程序搭档 × 20 个相同 seed（931000–931019），分别运行固定最大概率和固定种子采样，共 480 局。各配对初始完整状态哈希一致；非 guarded 的输出后改写均为零。每次先从 S_t 计算搭档动作，AI 决策接口不接收该命令；只在执行联合动作时合并。搭档规则在 protocol.json 中预先写入，完整轨迹保存每种模式/搭档前两个 seed；所有回合均有逐局指标。

原协调层的影响取决于搭档：程序协调搭档条件下，取消末端接管提高了配送；抢行搭档条件下则碰撞大幅增加。当前规则剥离最彻底的路径在这些诊断中 AI 配送为零，并出现断电，不能当作成熟协作模型发布。分数含每次碰撞 −200，因此必须一起看碰撞、配送和 AI 实际贡献，不能只用低分推断合作差或解释潜力。

这些结果支持下一步先研究无接管条件下的基础协作能力；不足以直接决定“训练得更激进”。严格消融同时移除了原输入特征和规则评分，存在分布变化，不能由其失败推出“神经网络从未学到任何行为”，也不能归因为某一单独组件。四层之间仅前两次变化分别隔离末端接管和 mask；最后一层合并前向与输入消融。若需要定位具体神经分量，应另做冻结协议的分量实验。

原始记录中的 `ai_distance_increasing_moves` 另有指标定义问题：空载时旧 navigation 字段可能等于当前格，正常移动也会增加距离。该列不用于本文表格或结论，不能当作退让/绕路证据；保留原记录并在 `metric_correction.json` 标记，未来命令使用明确的 `legacy_navigation_distance_increases` 名称。

另保存 30 个相同可达前状态的分支探针。与 guarded 的最终动作不同帧数分别为 actor_direct 5、unmasked_actor 2、learned_only 20；比较不改原状态或 RNG。固定/采样两份目录中的该探针均使用确定性动作，是同一诊断，不能重复计算样本。

## 验证及保存

- 907 项全套 Python 回归测试通过；另真实 HTTP 进程重启 1 项及严格自主观察一致性 2 项通过（共 910 项）。最终相关 21 项定向回归也通过。
- 10 项前端契约测试通过；真实浏览器检查四种模式、键盘、等待、回放、重开、中英文、刷新和页面尺寸，最终细节见 browser_report.json。
- 320 条真实生成观察：默认 PyTorch / NumPy 对各自改前输出逐位一致；learned-only 两实现最大 logit 误差 2.67e-5，全部 argmax 一致。严格自主观察另验 356 条：raw/合法 logits 最大误差 1.91e-5、mask 后概率误差 1.73e-6，所有确定性动作一致，推理不改状态/RNG。
- SQLite 事务、操作 ID / 请求摘要 / 状态版本保证幂等；跨会话读取拒绝；真实服务进程停止再启动后已确认状态和请求结果不丢失。原版本发生变化的已保存回合只能回看或另开新局。
- 原权重 `.pt` / `.npz` 和原验收文件哈希不变；原保存文件中仅 policy.py / numpy_policy.py 增加可选 forward 路径，默认参数保持旧行为。

数据单独写入 `output/audits/warehouse_autonomy/local_play.sqlite3`。内部 frames 保存前后快照、实际 Actor 分布、提交/执行动作；网页只读公开状态和客观计数。不会写入原参与者记录。
