### 脱离工具会话的真实退出监督

`--supervise --recovery-plan <绝对路径>` 先检查已登记的授权和源码，再独占写入
`supervisor-started.json`，使用本次 Python 和同一个 CLI 的 `--run` 启动子进程。
子进程输出保存在恢复目录 `run.log`。监督器实际调用 `Popen.wait()`，返回后原子写入
`supervisor-exit.json`，观察方式明确标为 `source_bound_subprocess_wait`，不标作工具观察。
收据绑定精确命令、父子 PID、起止 UTC、CLI 源码 SHA、日志，以及成功时的 result 和 completed 封条。
非零退出原样记账并使监督器失败；未成功 spawn/wait 只记独立失败收据，不编造退出码。
已存在监督启动收据或已消费恢复 claim 时不能再启动。外部调度方可将监督器放入独立会话，
工具会话重启不影响监督器等待和记录子进程的真实退出。
