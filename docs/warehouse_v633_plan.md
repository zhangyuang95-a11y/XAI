# v6.33：原核心输出不变，重新学习未保护叶的公开支持

2026-10-22，运行前登记。v6.32完整12项及独立复核完成，但只有1／6满足可靠性与数值要求；固定表上界有三项不足45%。
新试验统一使用六个v6.32 oblique程序，不逐角色拼接。NN为同一冻结v6.20双Actor，深9／256叶、每节点／叶最多3公开源不变。

## 方法

原v6.26保护区域的每个后代叶维持完整输出与原证书。只优化其余叶的公开支持、输出系数、合法witness和温度。
每叶保留现有模型，最多拟合8个不同支持／witness组合：现有支持重新拟合、物理合法的NN概率质量最大witness，
随后根据完整NN分布残差更新前向扩展和条件支持交换。交换依次比较不同旧支持位，避免8次调用都只修改同一位。
优化目标保持物理掩码后完整五动作分布交叉熵，沿用已有稀疏叶核、L2和系数约束；不引入教师动作或隐藏特征。
候选选择沿用v6.26完整分布代理分数，平局偏好更少公开源。有限搜索的全局optimality gap未知。

支持训练／选择按原fit900完整场景划分80%／20%；无两边曝光则保留原叶。
选中改变的叶才用完整fit900固定所选支持重新拟合，再由原cal150校准温度，每次均重新证明路径合法。
资格与验证不用于选择支持，输出此时明确没有继承资格。所有原保护区域须逐位保持。

随后固定新完整输出，使用原v6.32三特征置信划分：fit中600 sampled场景拆300拟合／150风险／150选择，
保留原子树，27／30稳定性规则和四个有限分配权重不变。所有条件与分配锁定后才作outer资格与验证。
支持刷新使用fit900，包含置信划分的风险／选择场景；这是明确登记的旧开发设计实验，fit-only代理不是新独立证据。
基础旧程序同样曾使用fit900。不得把这批场景写成新确认；真正锁定后仍须用全新不重叠fit/cal/qual/validation和压力场景确认。
