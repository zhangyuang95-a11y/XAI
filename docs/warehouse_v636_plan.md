# v6.36：先学习上下文，再对动作叶证明物理合法

2026-10-22，完整六单元运行前登记。v6.35未通过且独立复核已完成。本轮统一回到六个v6.33最终程序，保持同一冻结完整NN、原v6.26保护前缀及完整叶输出，深度≤9、总叶≤256、每节点/叶≤3公开源及叶≤20系数。

## 可检验变化

v6.35要求每个划分立即找到98%/99%纯动作区域；本轮允许先作不纯上下文划分，随后在子区域中分清动作。每个结构性未保护根有旧子树、上下文深2、上下文深3三个固定选项。每个上下文树用fit900内部80%整场景的完整NN掩码后argmax标签拟合一个entropy CART，min_samples_leaf160，random_state0是固定工程控制。上下文最大深度为min(登记值,剩余深度−1)。每个节点只用一个公开特征，按存储float32系数及实际硬路由重新划分训练帧。

上下文末端取训练NN首选动作的众数，仅用来决定是否增加显式计数的物理合法位节点。若路径未证明此移动动作合法，增加legal_ACTION判断；左右叶都重新拟合完整五动作分布，不使用CART投票输出，不固定动作。所有合法性判断、空分支和回退均计入复杂度；剩余深度不足时不偷增节点。

## 拟合、选择及公平预算

沿用v6.35全路径拟合与证书内核：叶支持选择fit900内部80/20，完整fit900重拟合，cal150校准，存储后再证明。原保护区不改任何系数。整树有限选项只用原fit内部300/150/150场景及固定30次90场景风险切片选择，27/30、全部资格及选择一致率/KL门槛不变；分配四个预定权重0/.5/1/2、≤256叶。fit-only代理已有训练重用，不能称作独立确认。全部选项固定后才读取outer资格/验证各300场景，逐单元判定。

各根两个CART最多两次节点拟合调用。所有潜在新增叶上界为两模板的2^min(剩余深度,模板深度+1)之和；每叶预算72次拟合、320次证明。搜索3600秒、总4200秒，最多3worker、BLAS单线程，预扣并记录失败调用，无自动重试。未用余额不转移。不按角色拼接赢家。
