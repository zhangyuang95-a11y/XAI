# Warehouse v6.20 执行约定

候选 `warehouse-v620-01`。目标发布仍为 `policylens-three-domain-20261016.v6.0`，但发布、pilot 与正式训练默认关闭。v6.19 的失败结论和 Actor 原件只读保留。实现分支为 `codex/warehouse-v620-robust-program`；历史关闭点由 `archive/warehouse-v619-closed-20261018` 指向。

## 第一阶段：已用数据开发

只读取已使用的 v6.19 124 局及固定 v6.18 Actor。99 局自然采样分成三个独立的整 base 验证折，每折 33 局；其余自然采样分为拟合 30、校准 18、叶资格 18 局，25 局 argmax 仅进入拟合。两角色、全部帧、同 base 的所有记录始终归为一组。M0 同折重新拟合；M1 修复队列早停并采用 beam；M2 增加仅使用拟合 episode 的稳定解释覆盖首目标。

搜索最大 8 个不同初始拓扑、30 轮、20,000 次叶 API、beam 4、最多 2 步非增益过渡。48 是提议分页大小。每个初始点保留预算；不能用首批没有增益作为整轮早停理由。叶拟合保留 v6.19 的完整掩码分布目标和约束求解器。所有移动叶在重新拟合、校准和导入后均检查路径合法性，空分支计入容量。

18 个工作单元必须全部完成才选择方法。M1/M2 的每角色、每折均须解释覆盖 ≥40%、预期反馈覆盖 ≥35%、解释一致率 ≥97%、KL ≤0.20，非法原始动作及无证书路径为零。按最差角色/折解释覆盖选择，确定性平局规则写入配方。平均覆盖 45% 为目标，不能替代任何单折门槛。这些结果只是开发证据。

准备、拟合、汇总各自检查源码、配方、Actor、原始轨迹、完整 NN 目标与折分配哈希。输出目录排他创建；失败与中断写入收据，不覆盖重跑。这个入口没有环境 reset、Actor 更新或 PPO 权限。

## 条件路线：共同 BC

旧数据路线没有余量时，先做共同 BC 结构学习，再考虑新验收数据。内部树和 256 NN 分支使用既有相同前向计算，不新增硬残差上限。训练目标为公开教师的完整 Actor CE、0.20 内部树 CE、0.20 stop-gradient 完整 NN 到树 KL，加上仅在树首选动作等于公开教师时的稠密残差软惩罚。gamma 只试 0.01、0.03，最多两份 BC 配方。

这不是未合格外部程序反馈。BC 辅助目标不能进入 raw PPO。后续 raw/regularized 使用相同架构、完全相同的共同 BC 双 Actor 起点和场景序列。新的初始化、场景和动作 RNG 必须经过种子台账核验；提议中的 6160–6163 尚未获运行授权。

## 后续准入顺序

方法及源码锁定、种子清场后才采集新的 fit 100（50 自然/50 argmax）、calibration 25、eligibility 75、validation 75 局。BC 门槛为两角色反馈和解释覆盖 ≥35%、预期反馈 ≥30%、一致率 ≥93%/95%、KL ≤0.25、全帧合法且路径有证书。失败关闭候选，不调参复用新验证集。

通过后才运行同一固定 Actor 与程序的 216 条独立轨迹（24 base × 3 tasks × 3 draws），同时检查任务质量和程序；再运行三组开发配对预算 200k/300k/400k，选全部三对通过的最小预算。每个预算从相同 BC 重启。正式训练只用质量集选择配对与检查点，程序预审不能改变选择。之后依次一次性审计和留出；封存失败或中断消耗该次申领。

执行始终由冻结 NN 加物理掩码决定。程序只用于合格训练反馈和经审计且与当前动作一致的解释。raw 的外部程序反馈、损失和梯度为零。Pong/Kitchen 只核验现有收据、资产哈希与迁移后的执行一致性，不重复用过的留出集。三域所有门槛通过才开放 pilot，代理成绩不称为真人效果。
