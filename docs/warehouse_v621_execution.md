## 阶段 1：已消耗数据上的 18 项诊断

### 固定输入与完整 NN 目标

- 数据目录：`output/warehouse_v620_frozen/warehouse-v620-01-gamma003-precheck-01`。
- Actor 文件 SHA：`1b6310f6d93309fb17e64516519a71680ad3c30e73f222be27df4dff10da81ec`。
- robot_1：`7aee44859397b8cbe1bb9cd3b8541e82f2a080d884c83404fe1e4fd2a998eaf0`。
- robot_2：`17f2f75877421854c680fab07557f031389800a9503b14f060db5ff4f862fcf0`。
- 275 局全部保留：225 局自然采样、50 局 argmax；每角色 32,782 个物理帧，不删除碰撞、停机、低概率动作或困难状态。
- plan、result、internal、四个 collection 收据、四份内容寻址轨迹及 275 个 episode 收据全部校验字节 SHA。每局完整帧数同时与原始 outcome 核对。
- 原始双角色 Actor 身份、五动作物理掩码、连续公开状态哈希、动作 RNG 派生参数和 argmax 标记逐帧验证。
- 所有记录的五动作概率均用同一个冻结完整 NN 重新计算。程序拟合目标是该分布，不使用教师标签或某个 NN 分支的输出。

### 分折

`experiments/warehouse/v621_protocol.py` 使用固定字符串加整 base 身份的 SHA 排序；不查询模型输出，也不新建随机种子。

每折：

| 分区 | 自然采样局 | argmax 局 | 合计 |
|---|---:|---:|---:|
| fit | 75 | 50 | 125 |
| calibration | 25 | 0 | 25 |
| eligibility | 50 | 0 | 50 |
| validation | 75 | 0 | 75 |

同一 base 下的双角色和全部物理帧整体分配。225 个自然采样 base 各自只在一折作验证，50 个 argmax base 每折都只进入 fit。原自然采样的 task 数量实际为 **75／76／74**，不是严格各 75；哈希分层尽量平衡，每折验证每 task 为 24–26 局。

### 方法

| Arm | 方法 | 目的 |
|---|---|---|
| A | 当前 M2，在新开发分折上重新拟合 | 同数据、同分折基线，无历史程序热启动 |
| B | 编译固定 Actor 内部树拓扑，再拟合完整 NN 分布 | 判断内部结构是否在外部重新搜索中丢失 |
| C | 合法路径约束下的整树交替优化 | 判断现有局部搜索是否遗漏更好的划分 |

B 加入合法性 guards 后超过深度 5、16 叶或每节点 3 个源特征时，记录为该方法的**科学不可行结果**。不能更改复杂度限制，也不能将其伪装为工程错误重试。

三方法 × 两角色 × 三折，共 18 项。全部完成或记录科学不可行结果后才计算路线，不能看到部分结果就挑选方法。

### 预算与程序资格

- 每角色每折整次拟合：最多 8 个初始化、**合计最多 60 个搜索轮次**，最多 20,000 次叶优化 API 调用。
- 最后固定拓扑叶重拟合预留最多 16 次调用，包含在 20,000 总额内；合法性 guards、空分支都计入复杂度。
- 沿用 v6.19 叶分布优化器：epsilon=0.001、prior L2=0.0001、maxiter=200、tolerance=1e-6。
- 叶输出重新拟合、温度校准后，按最终首选动作重新证明完整路径合法。fit、校准、资格、验证 episode 互不重叠。
- 继承现有叶样本支持、跨 episode 支持、Wilson 一致率和完整分布 KL 资格，不将验证帧用于选择叶资格。
- 分别报告实际初始化、轮次、叶调用、耗时和内存。没有匹配的实际计算证据时，不声称某方法更省计算。

### 路线判定

每个可选方法必须在两个角色的全部三个折同时满足：

- 反馈覆盖 ≥45%，解释覆盖 ≥45%；
- 预期可反馈覆盖 ≥40%；
- 反馈一致率 ≥95%，解释一致率 ≥97%；
- 两种资格区域 KL 各 ≤0.20；
- 整树原始非法动作数、无合法路径证明数均为 0。

通过方法按最差解释覆盖、最差预期反馈覆盖、更小的最大合格 KL、更少的叶数和固定 arm 顺序排序。全不通过才进入共享结构 Actor 开发；一项通过即锁提取路线，不能在新验证后回头选另一方法。

对每个固定拓扑，另算逐叶合法固定动作可匹配当前 NN 的最佳一致率上界。这只诊断**当前划分**，不能宣称全部 16 叶树都不可能成功。

## 后续结构和训练约定

以下是已批准的后续设计，不是阶段 1 授权：

1. 独立双 Actor；学习树骨架满足深度≤5、叶≤16、每判断≤3 个公开特征，移动叶从开始即有合法路径。
2. 外部程序编译同一拓扑后拟合完整 NN 分布。核心叶使用 `z_NN=t_leaf+r(s)`；非核心区保留 256 宽 NN。
3. 核心区主配方 `||r||∞≤0.35`，校准偏移 `||e||∞≤0.05`，同一物理掩码下 KL 上界 0.08；动作间隔须至少 `2(0.35+0.05)+0.26`。浮点、采样动作及实际覆盖独立检查。
4. 不根据当前匹配程度动态逃逸或删除核心状态。残差仍须对状态有非零表达，不能强行令程序等同完整 NN 或注入扰动制造 RCPD 梯度。
5. 三个开发初始化；当前加性 Actor 对照、新结构主配方，以及仅在主配方任务质量不足时可用的预注册 `b=0.50` 备用结构。最多三种配方 × 三初始化。
6. 开发每个初始化必须配送≥5.5、碰撞≤6、停机≤5%、双角色反馈/解释覆盖≥45%、预期反馈≥40%、一致率≥95%/97%、KL≤0.20、非法及无证书路径为 0；另外逐动作、逐 task 报告移动覆盖，不能靠 WAIT 隐藏不足。
7. 新 275 局预检维持原门槛：覆盖≥35%、预期反馈≥30%、一致率≥93%/95%、KL≤0.25。通过后才做 24 base×3 task×3 draw 的 216 条压力轨迹，物理回放沿用同一轨迹，不增加质量样本数。
8. 开发 PPO 用三个 raw/regularized 配对，200k/300k/400k 中锁定全部配对通过的最小预算，每个预算从相同 BC 重启。75%前冻结拓扑；75%/84%/93%提取；λ=0.01 于80%–85%渐增；每 PPO epoch 重验。
9. raw 的外部程序反馈、损失和梯度严格为0；regularized 双角色都必须真实收到程序梯度。真实停机事件的 cost critic 只训练权重。执行不存在动作改选控制器。
10. 正式配对只按质量选择后再作程序预审、一次性独立审计、每 task100新种子留出。任一封存失败或中断即关闭该候选、递增发布版本并分配新封存种子。
