# v6.31前置诊断：单叶动作目标混合没有额外收益

2026-10-22。此处v6.31仅指探索目录，尚未登记或准入新候选。
在已关闭v6.30后，针对事后发现的第0折角色2源叶54做两个预设损失对照。
它未被原父程序保护；旧结构、保护区域和NN文件均不修改。

使用旧600个sampled-fit场景，按任务和完整场景固定分成480拟合／120支持选择。
拟合叶内2012帧、选择509帧；旧校准、资格、验证分别有592／1212／1215帧。
资格和验证只在预设拟合后报告，不选择支持、温度或混合权重。
两个目标固定为原完整NN五动作分布p，以及`(p + 0.2 onehot(argmax(p))) / 1.2`。
选择、温度校准、KL与动作一致评估始终使用原p，混合目标从未提供环境动作。
目标改变也会影响现有拟合器的数据相关初始化／正则锚，不能将该配方对照解释为单独硬目标项的因果效应。

两个新配方的验证一致率相同；重新拟合相对原叶增加0.49383个百分点，混合目标没有额外动作一致收益。
不能据此断言所有权重或所有叶均无效，也不能把单叶变化写成总体解释覆盖提升或模型通过。
两者最终选择同样的3个公开源：`self_carrying_task_1`、`self_carrying_task_2`、`order_0_self_remaining_mission_distance`。
后续需要检验不同条件划分或支持表达；当前不据此启动全域混合目标训练或搜索权重网格。
