# v6.42 加速恢复 v3

此版本仅改进数值恢复与重复校验。原407份研究源码、6份恢复源码、全部旧输入和失败/中断证据保留。

- 同一个完整PPO、物理环境、随机流、20k预算和原始截止时间；不新增训练场景、不更改任何科学门槛。
- 仅当旧任务没有新reset、物理帧或新提交，且唯一重放提交与原17824提交逐类型/浮点位一致时，独立停止器才允许停止未提交数值重算。实际旧supervisor的OS wait(-15)必须保留。
- v3从原raw18600、regularized16800完整检查点恢复。已提交1024帧只精确重构一次，不重复计入训练步数。后776帧使用原记录；之后才按剩余清单继续。
- 每次校验仍完整读取所有不同文件。重复出现的同一路径/SHA只校验一次；同路径冲突SHA、变更、缺失、符号链接均拒绝。
- raw不重建已无训练用途的程序源池。regularized实际重建原生ObservedPool，使用新PreparedProgram；当前NN资格每次重新计算。
- canonical producer显式登记新源码和守卫。每个新NN仍必须经原生全部帧scalar重放后才签发原生证书并允许梯度。旧记录目标只按原承诺复用，不伪造证书。
- checkpoint/event载体调用冻结v2函数，明确保存v2载体版本；v3执行器、claim、source contract和cutover另行绑定。独立读者必须显式支持v3。
- raw外部程序梯度必须为0，regularized两角色须有真实接受的正程序梯度。执行动作始终来自NN与物理掩码。

数值训练完成不等于模型验收。完成后独立检查更新链、NN哈希、程序当前资格，并进行新质量评估，输出真实指标；pilot仍关闭。
