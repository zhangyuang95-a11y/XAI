# Warehouse v6.22：保留 v6.20 的容量与联合训练实验

候选：`warehouse-v622-v620-preserving-01`。目标发布仍为
`policylens-three-domain-20261016.v6.0`；任何开发收据都不能开启 pilot。

## 固定基线

- 完整双 Actor NPZ：`1b6310f6d93309fb17e64516519a71680ad3c30e73f222be27df4dff10da81ec`。
- robot_1：`7aee44859397b8cbe1bb9cd3b8541e82f2a080d884c83404fe1e4fd2a998eaf0`。
- robot_2：`17f2f75877421854c680fab07557f031389800a9503b14f060db5ff4f862fcf0`。
- 旧75个开发 episode：配送14.9333、碰撞2.84、停机1/75。这不是独立留出结果。
- 旧程序/模型/失败收据及科学源码不变；新文件具有独立版本、schema和源闭包。

## 决策顺序

1. 阶段A仅使用已花费的275个完整 episode、32782个物理帧/角色和原三折分区。
   A16复用旧独立审计收据；A32运行M2的6层/32叶版本；B32编译原内部拓扑的
   显式合法性guard后重拟合完整五动作分布。B32预期25/27叶，并不等价于完整NN。
2. 两角色三折全部完成才按预注册排序选择。门槛：反馈/解释叶覆盖45%，期望反馈40%，
   一致率95%/97%，KL≤.20，所有原始程序动作合法且全路径证明。实际反馈覆盖单独报告。
3. 仅在完整批次及独立算术审计均证明A32/B32无方法合格时解锁D32。
   D32对最多4个拟合集最大模板及冻结叶输出表做32叶预算DP；不能删除guard后提升子树。
   证书只涵盖已声明且完成的模板/冻结表，全部稀疏树的最优性差距未知。
4. 全部失败即关闭本候选；不进行新rollout、PPO、最终审计或留出测试。
5. 有合格方法后才建立新种子清单、275 episode新确认集及216压力轨迹，再进行配对PPO。

## 计算与训练约定

- 每角色每折：A32最多8起点、全局60轮、19968搜索叶调用+32最终叶调用、90分钟。
  保留10分钟用于最终重拟合/证明；B32最多32最终叶调用、10分钟。
- D32生成最多20000叶调用，完整节点表最多508调用，另留32调用余量；最终程序直接
  保留冻结表输出，最终重新优化调用为0。校准温度变换单独记录，DP证书不扩张到连续最优。
- 任意时刻最多3个独立作业，每作业1个BLAS/Torch CPU线程。预算是上限，不是耗时承诺。
- 程序只接受拟合前公开特征，深≤6、叶≤32、每判断≤3源特征；空分支及guards计容量。
- 后续PPO每组前4000联合步Actor冻结，仅完整episode训练critic，包含在总预算内。
  零停机正例如实记录；未完成episode不视为零停机，不补手写风险标签。
- raw/reg共用原v6.20完整双Actor起点及新的critic/优化器。只有本版本保存的完整训练态
  可以称为resume；导入旧NPZ不能恢复旧critic、优化器或历史RNG。
- 两组共同参考KL方向为reference→current；每角色目标.01 nat，beta初1、范围[.001,100]，
  只在实际Actor更新后调节。参考训练缓冲/当前训练状态各50%，验证数据不进入梯度。
- regularized外部程序KL按全部物理帧平均，75%/84%/93%提取，80%—85%升至lambda=.01。
  每epoch独立重验，只对合格且动作一致行反馈；raw程序损失/梯度严格零。
- 新候选开发配送≥同场景基线95%，碰撞≤min(6,基线+1)，停机≤5%；逐随机流分别通过。
  三个继续训练随机流不被描述成三次独立BC复现。

## 执行入口

`scripts/run_warehouse_v622_capacity.py`只支持源绑定的prepare、单作业与完整汇总。
`scripts/audit_warehouse_v622_capacity.py`只读输入、独立重建路由/资格/指标/选择/预算；
不得调用生产程序的指标或拟合器。所有新输出使用独占写入，不能覆盖或静默重跑。

配方位于`configs/warehouse_v622_recipe.json`，完整源码在prepare时逐文件复制并只读保存。
阶段A环境重置、Actor更新、PPO步数全部为0。模型/解释门槛失败后不通过手写控制器补救。

## 文献与适配限制

- [GOSDT, ICML 2020](https://proceedings.mlr.press/v119/lin20g.html)：借用有限空间的DP思路，
  本实现不继承对全部三特征斜树的最优性保证。
- [Kickstarting, 2018](https://arxiv.org/abs/1803.03835)：NN独立采样、固定NN只提供分布梯度。
  本项目固定参考KL保留机制需要Warehouse验证，论文不保证配送不退化。
- [PROPEL, NeurIPS 2019](https://proceedings.neurips.cc/paper_files/paper/2019/file/5a44a53b7d26bb1e54c05222f186dcfb-Paper.pdf)：借用周期程序投影，
  不采用其程序执行方式，也不声称其理论直接覆盖当前非凸NN/有界搜索。
- [MAVIPER, ECML/PKDD 2022](https://arxiv.org/abs/2205.12449)：支持分析协作关键状态，
  本轮不引入未经校准的任务Q或让抽取程序控制采样。
