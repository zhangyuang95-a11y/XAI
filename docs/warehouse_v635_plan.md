# v6.35：重建受保护区域以外的动作合法子树

2026-10-22，运行前登记。v6.34完整12项及独立复核未达准入，两项固定表可靠解释覆盖上界不足45%。
统一从六个v6.33最终程序出发，NN、原保护区域、深≤9、叶≤256、每节点／叶≤3公开源及叶≤20系数不变。

## 结构与物理证明

仅按原保护前缀结构枚举所有最大未保护子树根；不得按验证NN标签挑根，也不修改任何原保护前缀或原叶输出。
每根最多学4条NN动作条件，受剩余深度限制。两种固定训练精度目标98%、99%，旧子树始终为可选项。
节点从完整掩码后NN分布提取训练标签“NN首选动作是A”，用公开变量学习条件；不引用任务教师、私有目标或路线历史。
若路径已证明A合法，条件最多3公开源；否则在同一计数节点组合legal_A与最多2公开源条件。
组合仍是稀疏线性判断：用由公开域界推导的物理位系数保证位为0时不可能走真分支，保存精确有理数上界与FP64误差界。
全部合法性判断、空分支和默认叶计入实际复杂度。不提高深度，不取消显式物理位证明，不给Actor增加固定动作锚。
每个真分支和剩余分支的叶都拟合完整五动作概率，不固定动作、不输出运行时指令。NN执行始终不读取这些程序。

## 拟合与选择

条件仅使用fit900内部按完整场景划分的80%训练场景。每节点对四个移动动作学习有限稀疏logistic方向，
最多7个支持拟合，目标仅是提议NN高度一致区域；完整NN分布仍是所有叶的交叉熵拟合目标。
叶支持使用同一fit内部80%／20%选择，选定后用完整fit900重拟合，再由cal150校准，每次重新证明合法性。
两种子树与原子树形成固定有限选项。原保护区域作为固定选项不更新系数或结构。
仅用旧fit中的300拟合／150风险／150选择子分区评分，保留叶资格、27／30重复稳定性、选择一致和KL要求及四个预定分配。
基础与新输出都用过fit900，此fit-only代理不是独立新数据；本轮仅是明确的已花费开发数据设计实验。
所有选项及分配锁定后，才用原outer资格300及验证300测量最终指标。六单元统一完成，不按角色拼接方法。

## 门槛与预算

逐单元保留F/E覆盖≥45%、预期F≥40%、F/E一致≥95%／97%、KL≤.20、原始非法与未证明0，以及fit-only可靠覆盖。
预算按结构根数量预先计算：每根两模板，每模板规则≤4、条件拟合≤4动作×7支持／规则；每新叶≤72叶优化、≤320证明LP。
每单元3600秒搜索、4200秒总时间，最多3进程、BLAS单线程，所有优化预扣账、失败照计、无自动重试。
程序语言另行版本化；原读取器与旧收据不变，新读取器拒绝错误目标NN哈希或不匹配证明。
原保护锚NN哈希与当前被解释NN哈希分开记录，本轮两者相同；更换当前NN并不自动授予保真资格。

## 验证与边界

先验证全部移动位、双公开源符号与域角点、精确物理上界、NN哈希拒绝及旧读取器拒绝。
再以合成概率目标实测学习、全分布拟合、路径证明、组合、保护输出保持及独立前向；合成测试不算模型通过。
正式开发输出逐角色六行完整指标、所有候选、训练来源、数值证明、固定表与选择账本，独立复核后才决定是否锁定。
若任何门槛失败，不采新确认、不启动PPO、不开放pilot。全新确认／压力、真实配对训练、正式选择及一次性审计／留出、三域绑定发布均保留。
NN更新、PPO步、新reset及程序训练反馈梯度均0。程序中的动作条件来自NN拟合，只服务解释和后续合法梯度，绝不成为任务分配或避让控制器。
