# Warehouse v6.30：学习可靠分区，保留完整输出

候选 `warehouse-v630-stable-partitions-01`。这是v6.28→v6.29的后备程序方法；
只在原v6.29全部24项结算、真实回收、确定性审计完成且无全通过容量时启动。
若原方法通过则跳过新候选，继续原winner，不新增竞争实验。
NN仍是完整冻结v6.20双Actor，程序不选择环境动作。

## 固定起点与三臂

六个角色/折一律使用相应v6.29 **G128内部search-best**，不按角色选容量，不导入外层重拟合程序。
来源在依赖完成封条中固定，验证原内部分区、Actor哈希、数值证书及旧终态。
新树统一深度≤9、叶≤256，每节点及叶≤3个公开源、叶≤20系数；全部合法/空/回退分支计数。

- C0：不细分的同源对照，不调用分类器。
- P：只对原v6.26保护区域的叶学习分区。
- A：对全部叶学习分区。

每臂2角色×3折，共18项，均需完整结算和计算完成；三个臂不共享学习缓存或余额。
最终只在P/A之间按固定顺序选第一个六单元全通过的方法，不能按单个角色混选。

## 条件学习和叶预算

使用已花费1650场景开发池，不宣称新独立确认。每折outer.fit中的600个sampled场景按任务内case ID排序：
前100/任务用于拟合，随后50/任务用于风险资格，最后50/任务用于选择，即300/150/150。
argmax300不进入条件学习；外层calibration150、eligibility300及validation300均不参与条件或选项选择。

每个允许且有足够训练帧的旧叶仅拟合一次axis-aligned entropy CART，最多增加min(3,剩余深度)层，
每叶至少40训练帧，错误类权重4、正确类权重1，random_state=0为固定工程控制，不称新随机流。
目标为当前固定程序首选动作是否与完整NN掩码后首选动作一致；分类器的类别/概率全部丢弃，
只提取公开条件。叶原有五动作logits模型、支持、归一化和温度全部冻结。

枚举该深3模板的全部“终止/保留双侧子树”剪枝，不提升子树。
所有评分重走存储float32条件的共享硬路由，不使用sklearn路由作为最终事实。
在150个风险场景中，以SHA256(方法、重复编号、原场景ID)构造30个任务平衡的90场景子集。
子叶须在完整风险集过原资格条件，并在至少27/30子集中通过相应用途资格。
选择集上还须达到反馈/解释一致≥95%/97%、KL≤0.20，才能计入“可靠覆盖”评分。
重复子集彼此相关，只是选择规则，不是置信区间或独立样本。

冻结每个局部选项的E、F及expected_F帧数，再分别用四个预定权重0、0.5、1、2进行叶预算DP：
首目标为 `E/(0.45N)+w*(F/(0.45N)+expected_F/(0.40N))`，再按E、expected_F、F排序。
每次DP仅对该固定选项表和可加目标精确最优；不声称对未知条件或非线性全局门槛最优。
四个完整候选只用选择集排序：先可靠覆盖F/E≥45%、expected_F≥40%，再沿用v6.29严格可行性/最差缺口评分。
不使用外层结果改选四个分配偏好。

## 证明、最终处理与预算

允许原叶变为完整子树，但所有后代必须保留完全相同的原输出payload；
原保护路径的全部祖先与原区域不变，新的子区域不继承资格。
旧精确对偶向量对新增路径约束补零，重新独立计算完整有理数上界并要求与旧界相同；
新旧合法事实均从规范物理掩码判断重算。每个最终叶重新验证数值证书。
这种结构只改变资格划分，**整个程序的完整输出分布和全树NN一致率不会因细分改变**。
只有经独立资格验证的解释/反馈覆盖可能改善，不预先承诺改善。

每单元限node fit256次、叶fit0次、证明LP0次；搜索累计1200秒，最终处理600秒，总1800秒。
最多3个worker，BLAS单线程，不与v6.29优化进程重叠。失败调用预扣不退款，无自动重试。
检查点保存选项表、游标和分配候选；本版不发放中断后的恢复或追加预算权限。
计时、求解和证书错误不能变成通过；失败收据保留，未测数值留空不记0。

最终不重拟合任何系数或温度，只在原outer.fit900/cal150/elig300/valid300上重新判定资格及测量。
calibration不用于本方法的参数更新。所有帧对照原程序logits和完整五动作分布逐位相同。
独立审计重放局部评分表、四个DP、选中候选、全部数值证明及逐子叶资格，不重新拟合分类器。
