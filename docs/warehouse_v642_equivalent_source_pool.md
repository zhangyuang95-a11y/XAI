# 程序源池审计的完整输入等价复用

此优化仅用于20k之后的外部程序拟合，训练执行器及其源快照不变。

必须先实际执行一次原生完整源池审计。第二份源池仅在所有完整episode的场景清单、行为双Actor的完整张量/模型语义、私有初末环境SHA和每一帧完整事件的规范JSON SHA均相同时，才能通过输入等价证明复用该模拟结果。全部不同输入文件仍完整校验实际SHA；无抽样、无stat缓存。不同且合法的输入退回原生完整审计；损坏、缺失和不合法输入拒绝。

派生的ObservedPool保留原生数据/来源校验，并显式绑定新实现、上游真实原生审计和全部等价证明。程序源政策结局仍只属于源政策，不能称为最终NN质量。不会伪造ReplayedTargets私有token或复用最终NN概率；raw和regularized的最终NN目标仍各自调用原生完整scalar校验。新质量场景仍独立收集并逐帧重放。

没有减少场景数、改变拟合/资格分区、程序语言或验收阈值。
