## 只读分解：下降主要发生在重新判定叶资格

冻结已结算程序，不拟合、不校准、不求LP、不采集新环境。独立forward和基本指标算术重放一致。
分别改变评估帧、资格集合和最终叶输出，得到：

| 解释覆盖测量 | G64 | G128 |
|---|---:|---:|
| 搜索程序，内部帧和内部资格 | 43.31% | 45.01% |
| 同程序，外层帧、仍沿用内部资格（仅诊断，不可准入） | 43.57% | 44.99% |
| 同程序，外层帧、重新判定外层资格 | 38.87% | 42.00% |
| 最终重拟合/校准程序，沿用上一行叶集合 | 38.87% | 42.00% |
| 最终程序与正式外层资格 | 38.87% | 42.00% |

在这两个单元中，主要覆盖差来自外层资格重新判定，不是单纯换验证帧，也不是最终重拟合/校准进一步损失覆盖。
这不表示资格判定有错：独立资格数据确实发现部分叶的一致率低于95%。
例如共同叶10的内部资格一致率95.21%，外层为93.01%；共同叶9为96.98%→94.10%。
G128一些叶同时新获资格，但净覆盖仍减少。数据量、叶内异质性和内部多候选选择都可能有关；
此分解未单独识别各原因的因果贡献，不能宣称仅增加资格数据就能解决。

下一候选的重点应是用fit内部整场景重复分区检验资格稳定性、提高边缘叶的一致性余量，
并分析永久保护但在新数据失去资格的区域。任何方法修改需另行登记；
本诊断不改变正在运行的v6.29方法、预算或选择规则，不导入其训练缓存，也不使用新确认/封存数据。
