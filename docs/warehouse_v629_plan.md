# Warehouse v6.29：累积局部修补与合法位合取证明

候选 `warehouse-v629-cumulative-guard-01`。方法在看到 v6.28 外层结果之前登记。
v6.28 源码、数据、作业、资格标准与预算不改动，不中断其18项对照。

## 证据和可检验的改变

只在 inner.fit450 诊断：未保护区域中，NN 首选动作不在旧路径可证明合法集合的
比例为六单元的11.66%、8.69%、12.48%、9.72%、12.41%、10.11%。这不是实际非法率。
部分大叶该比例约49%。另有6个路径产生独立正收益，其中11对路径互不包含；
v6.28 同轮 current 固定，不能立即组合。这些是设计依据，不是新候选通过证据。

1. 对最新接受的完整程序应用**局部替换**，在同一轮立即累积；不重放过时的整树。
2. 数值路径和合法集合完全相同的未改叶也不重拟合，只重绑树SHA/叶ID并独立验算旧对偶。
   每次整树重新路由、判定资格、评分；永久保护的v6.26叶保持原规则。
3. 一个合法性条件可合取2或3个公开物理合法位：系数严格为同号±1、阈值为半整数。
   各位在路径上明确出现；全部16种移动掩码由独立有理数检查器穷举。
   非规范条件不得产生新合法事实。3位加1位的两层判断可证明四个移动动作。
4. 使用单纯合取、合取加完整NN分布CART子树等候选跨过中间低分结构；
   所有合法性/空/回退叶计入64/128/256叶及深9限制，每判断及叶最多3个公开源。
5. 保留独立全局最优与最多3条探索路径，每个局部路径最多占一个探索位置，先去重再截断。

运行时仍只有冻结完整NN和物理掩码选动作。新语言只改变训练/解释程序。
旧v6.26/v6.28资产、读者和证书语义不修改；新资产绑定新语言、规范逻辑证据、旧数值证明、Actor和域哈希。

## 预登记实验

等候已核实存活的v6.28监督器及全部18项结算；核实真实进程身份，禁止用遗留锁推断进程存活。
全局最多3个优化worker，不与其重叠争用这3个配额。任何缺失的依赖如实失败，不重启旧作业。

四臂：C64仅累积修补，G64/G128/G256再加合取证明；2角色×3折，共24项。
每项从**对应容量v6.28已封存search-best**出发，不导入v6.28外层重拟合后的program，
避免把外层fit中包含的内部评分/资格数据当作未见数据。C64/G64相同起点。
旧外层结果只作封存/依赖核验，不用来选择新拓扑、支持或超参数。
若旧作业因硬截止结算失败、未写search-best，仅允许只读取其最后已提交CAS best；
绑定终态结果/完成封条、检查点/registry/best SHA，核实旧计划和作业身份、全部终态调用账本、
内部episode和场景分区及完整证明。旧检查点只代表已提交前缀，不声称旧搜索完成或旧门槛通过。
此导入不恢复旧作业，不追加其调用；文件优先、CAS后备顺序固定，不根据得分切换。

使用同一1650局及同一预登记内外分区；这是一组共同开发数据，不称新独立确认。
每项预算叶80k、节点4096、LP400k，搜索4800秒、最终1200秒；统一预留2048叶调用和13312 LP。
4770秒累计软截止、4790秒独立硬截止；安全返回的best即使触发计时器出口复检仍进入最终指标阶段。
三个G容量预算相同；最多14轮，不因暂时停滞提前结束；全部失败调用仍预扣。
第一轮全部最大不含保护叶的区域须完整枚举；新后代在随后轮次按fit分布误差优先探索。
安全暂停保存局部队列、最新工作程序、全局最优、探索分支及账本；崩溃不自动重试。

每角色/折：反馈与解释覆盖≥45%、预期反馈≥40%、一致≥95%/97%、KL≤0.20、
原始非法/未证明均0。覆盖分母、资格Wilson界、样本数、场景数和单局占比不变。
24项结算且独立算术回放后，选六单元全部通过的最小G容量；不能按角色混选。
C64为机制对照，不因其分数挑选新方法。预算不足不证明容量或语言不可行。
